## 💡 About The Project

Traditional chat interfaces are often rigid, impersonal, and restricted to simple text boxes. **Lexa AI** is built from the ground up to redefine what an AI virtual assistant feels like — blending **emotional intelligence, real-time voice, vision OCR scanning, adaptive personalization, and 3D visual dynamics** into a unified modern workspace.

Whether brainstorming technical architectures, analyzing codebases, scanning physical documents via live camera feeds, speaking naturally through voice chat, or conducting grounded web research with live citations, Lexa seamlessly adapts to your workflow and personality.

> *"More than an AI chatbot — an emotionally aware companion engineered for speed, creativity, and deep productivity."*

## ✨ Key Features

### 💬 Intelligent Real-Time Streaming Chat
* ⚡ **Token-by-Token Streaming:** Ultra-low latency responses using Server-Sent Events (SSE).
* 🧠 **Multi-Tier Model Routing:** Select between Fast, Balanced, Pro, Expert, and Ultra model tiers (Google Gemini, Anthropic Claude, OpenAI).
* 🎨 **Markdown & Code Highlighting:** Rich syntax highlighting with copy-to-clipboard, markdown tables, and safe HTML rendering.
* 🧵 **Thread & History Management:** Organize, search, pin, export (JSON/Markdown), and delete chat sessions effortlessly.

### 🎙️ Real-Time Voice & Talking Assistant
* 🗣️ **Conversational Voice Mode:** Hands-free two-way speech recognition powered by Web Speech API.
* 🔊 **Studio-Quality Voice Output:** Integrated with **ElevenLabs API** for lifelike expressive vocal tones.
* 🌊 **3D Audio Visualizers & Strands:** Real-time WebGL audio reactive waves and Three.js fiber particle animations.

### 📷 Vision OCR & File Attachments
* 📸 **Live Camera Scanner:** Capture notes, whiteboards, or documents directly from your webcam with instant OCR text extraction.
* 📎 **Multi-Format Document Parsing:** Upload PDF, Word (.docx), Excel (.xlsx), CSV, Markdown, Code, and image files.
* 🖼️ **Image Understanding:** Vision-capable analysis of charts, wireframes, diagrams, and screenshots.

### 🌐 Live Web Search & Citations
* 🔍 **Grounded Real-Time Search:** Live internet search integration for breaking news, up-to-date documentation, and facts.
* 📚 **Source Attributions & Verified Citations:** Direct backlinks to authoritative source material with thumbnail previews.

### 🎭 Personality Modes & Smart Memory
* 5️⃣ **Dynamic Personalities:** Switch between **Professional**, **Creative**, **Academic**, **Casual**, and **Technical**.
* 🧠 **Persistent Context & Memory:** Remembers custom user preferences, coding styles, project context, and custom prompt rules.
* 🎯 **Focus Mode:** One-click distraction-free view hiding sidebars for immersive deep work.

### 🔐 Enterprise Auth & Performance
* 🔑 **Google OAuth & Supabase Auth:** Seamless social login and secure email/password authentication.
* 🛡️ **Hono REST API & MongoDB:** Ultra-lightweight backend architecture with rate limiting, JWT validation, and CORS security.
* 📱 **PWA & Offline Capability:** Progressive Web App with service worker caching and installable app experience.

## 🛠️ Tech Stack & Architecture

| **Layer** | **Technology** | **Description** |
| :--- | :--- | :--- |
| **Frontend Framework** | [React 18](https://react.dev/) + [Vite 7](https://vitejs.dev/) | High-performance reactive web application with fast HMR |
| **Language** | [TypeScript](https://www.typescriptlang.org/) | Strict type safety across client and server |
| **UI Components** | [shadcn/ui](https://ui.shadcn.com/) & [Radix UI](https://www.radix-ui.com/) | Accessible, customizable headless UI primitives |
| **Styling & Effects** | [Tailwind CSS](https://tailwindcss.com/) & [Lenis](https://lenis.darkroom.engineering/) | Utility-first styling with smooth scrolling & glassmorphic themes |
| **3D & Animations** | [Three.js](https://threejs.org/), [Fiber](https://docs.pmnd.rs/react-three-fiber), [Framer Motion](https://www.framer.com/motion/), [GSAP](https://gsap.com/) | Interactive 3D particle strands, audio waves & micro-interactions |
| **Backend Framework** | [Hono](https://hono.dev/) on Node.js | Ultrafast, lightweight web framework with minimal overhead |
| **Database & Cache** | [MongoDB Atlas](https://www.mongodb.com/atlas) & [Redis](https://redis.io/) | NoSQL conversation storage and high-speed session caching |
| **Authentication** | [Supabase Auth](https://supabase.com/auth) | Google OAuth 2.0, JWT verification, and user management |
| **AI & LLM Services** | [Google Gemini](https://ai.google.dev/) / Claude 3.5 / OpenAI | Advanced multimodal intelligence, reasoning, and streaming |
| **Voice Synthesis** | [ElevenLabs](https://elevenlabs.io/) & Web Speech API | Ultra-realistic voice generation and speech-to-text |

## 🚀 Getting Started

Follow these step-by-step instructions to get Lexa AI running locally on your machine.

### 📋 Prerequisites
- **Node.js** (v18.0.0 or higher) & **npm** (or `pnpm` / `yarn`)
- **MongoDB Atlas** database URI (or local MongoDB instance)
- **Supabase Project** (For authentication & Google OAuth)
- **Google Gemini API Key** or **Anthropic Claude API Key**
- **ElevenLabs API Key** *(Optional, for lifelike voice synthesis)*

---

### 📥 1. Clone the Repository

```bash
git clone https://github.com/parag8451/Lexa-AI-virtual-assistant.git
cd Lexa-AI-virtual-assistant
```

---

### ⚙️ 2. Backend Setup (`lexa-backend`)

1. Navigate to the backend directory and install dependencies:
   ```bash
   cd lexa-backend
   npm install
   ```

2. Create a `.env` file in `lexa-backend/`:
   ```env
   PORT=3000
   MONGO_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/lexa_ai?retryWrites=true&w=majority
   GEMINI_API_KEY=your_gemini_api_key_here
   ANTHROPIC_API_KEY=your_anthropic_api_key_here
   SUPABASE_URL=https://your-project.supabase.co
   SUPABASE_SERVICE_ROLE_KEY=your_supabase_service_role_key
   CORS_ORIGINS=http://localhost:5173,http://localhost:8080,http://localhost:3000
   ```

3. Seed initial database data *(Optional)*:
   ```bash
   npm run seed
   ```

4. Start the backend development server:
   ```bash
   npm run dev
   ```
   > 🚀 Backend will be active on **`http://localhost:3000`**

---

### 💻 3. Frontend Setup (`lexa-frontend`)

1. Open a new terminal, navigate to the frontend directory, and install dependencies:
   ```bash
   cd lexa-frontend
   npm install
   ```

2. Create a `.env` file in `lexa-frontend/`:
   ```env
   VITE_SUPABASE_URL=https://your-project.supabase.co
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   VITE_API_BASE_URL=http://localhost:3000/api
   VITE_ELEVENLABS_API_KEY=your_elevenlabs_key_here
   ```

3. Start the frontend Vite development server:
   ```bash
   npm run dev
   ```

4. Open **`http://localhost:5173`** in your browser to experience Lexa AI!

## 🌐 API Reference

| **Method** | **Endpoint** | **Auth Required** | **Description** |
| :--- | :--- | :---: | :--- |
| `GET` | `/health` | No | System health check, uptime, and status |
| `POST` | `/api/chat` | Yes (JWT) | Real-time SSE token stream for AI responses |
| `GET` | `/api/conversations` | Yes (JWT) | Retrieve all active user conversations |
| `GET` | `/api/conversations/:id` | Yes (JWT) | Fetch message history for a specific conversation |
| `DELETE` | `/api/conversations/:id` | Yes (JWT) | Delete a conversation thread permanently |
